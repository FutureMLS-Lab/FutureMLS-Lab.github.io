FOSCAR Accelerating Decode Attention over 2- and 4-Bit KV Caches through Affine Folding

Donglin Zhuang1,2, Pragaash Ponnusamy1, Xiaoxia Wu1, Shuaiwen Leon Song2, Zhongzhu Zhou1,2

1 Together AI   2 University of Sydney

FOSCAR moves scale and offset out of per-value KV reconstruction. Hopper uses BF16 Tensor Core operands, and Blackwell can feed packed INT2 codes into FP4 Tensor Cores after remapping.

How FOSCAR worksFOSCAR 的工作原理

Affine folding仿射折叠

Every decode step reads the KV cache. Packing it into 2 or 4 bits cuts memory traffic, but reconstructing each value still takes GPU instructions. FOSCAR builds Tensor Core operands from packed codes and applies each group's scale to a matrix input or partial result. The offset enters as an output correction.

每个解码步都要读取 KV 缓存。打包成 2 或 4 bit 可以减少内存流量，逐值重建仍会消耗 GPU 指令。FOSCAR 直接从打包编码构造 Tensor Core 操作数，把每组的缩放应用到矩阵乘法的输入或部分结果，并用偏移修正输出。

Try the arithmetic on four keys用四个键看折叠怎么算

Use query Q = [1, 2, 1, 1], INT2 codes q = [0, 1, 2, 3], scale s = 0.5 and offset z = −1. Reconstructing the keys gives [−1, −0.5, 0, 0.5]. Its dot product with Q is −1.5.

设查询 Q = [1, 2, 1, 1]、INT2 编码 q = [0, 1, 2, 3]、缩放 s = 0.5、偏移 z = −1。先重建得到键 [−1, −0.5, 0, 0.5]，与 Q 的点积为 −1.5。

s · dot(Q, q) + z · sum(Q) = 0.5 × 7 − 5 = −1.5

The folded route gets the same result in exact arithmetic. It applies scale and offset once to this group's contributions.

在精确算术下，折叠路径得到同一个结果。缩放和偏移作用在这一组对结果的贡献上。

From packed bits to Tensor Cores从打包位到 Tensor Cores

TMA moves packed tiles into shared memory. On Hopper, consumer warpgroups construct BF16 operands and accumulate in registers. On Blackwell, the INT2 path zero-extends codes into FP4 operands in shared memory, and the matrix products accumulate in tensor memory (TMEM).

TMA 把打包分块搬到共享内存。Hopper 的消费者 warpgroup 构造 BF16 操作数并在寄存器中累加。Blackwell 的 INT2 路径通过补零构造 FP4 操作数，放入共享内存，矩阵乘积累加到张量内存（TMEM）。
